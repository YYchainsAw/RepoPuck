RepoPuck 是一款 Windows 优先的轻量级 Git 桌面工具。它把文件暂存、分支切换、提交和推送放进随叫随到的悬浮面板，并复用系统 Git 凭据；AI 提交信息采用自带密钥且完全可选。

## Acceptance readiness

RepoPuck already has the documentation items highlighted in HelloGitHub's
[review guidance](https://github.com/521xueweihan/HelloGitHub/issues/271):

- project introduction and features;
- quick start and requirements;
- public releases and release notes;
- FAQ and contribution guidance;
- MIT license;
- active issues and recent maintenance.

For a self-recommended project, stars are optional under that guidance, but
activity and repository insights are still reviewed. Acceptance is therefore
more likely after the WinGet submission succeeds and the repository shows a
small amount of real user feedback or completed issues.

## User-owned action

Submitting creates a public issue under the user's GitHub identity. The account
owner must:

1. sign in to GitHub;
2. search HelloGitHub once more for the RepoPuck URL to avoid a duplicate;
3. open the Chinese project form;
4. paste and review the material above;
5. upload or link the demo media;
6. submit the public issue and respond to reviewer questions.

HelloGitHub does not require a fork, signed commit, or CLA for this issue-form
workflow.
